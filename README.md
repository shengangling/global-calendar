# 环球万年历 · 网页版

公历、农历（干支、生肖、月相）、二十四节气、伊斯兰历，以及 33 个国家和地区的公共假期，最多同时对照两个国家（默认中国 + 阿联酋）。

- 月 / 年 / 假期一览三种视图，⌘K 搜索跳转，日期计算（含各国工作日）
- 我的事件：农历生日、按时区提醒；可导出 .ics 导入手机日历，由日历到点提醒
- 中国放假调休：同步国务院公告（holiday-cn）；其他国家：Google 公共假期日历，由 GitHub Actions 每 6 小时更新 `netdata.json`
- 数据只保存在你自己的浏览器（localStorage）

同一套代码也打包为 macOS 菜单栏 App（多了菜单栏小日历、开机自启、合盖补发、iCloud 日历同步等原生功能）。
